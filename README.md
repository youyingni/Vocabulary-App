# 📘 單字本 (Vocabulary App)
這是一個專為背英文單字設計的漸進式網頁應用程式 (PWA)。支援滑動卡片模式、自動播放三種口音發音 (US → GB) 以及個人化星號收藏，非常適合多益 (TOEIC) 及 Parker 單字學習。

## ✨ 特色功能
*   📁 **分類資料夾**：區分「新制多益 New TOEIC」與「Parker」兩大單字本。
*   🃏 **極簡卡片模式**：
    *   **點擊卡片**：直接播放單字發音。
    *   **向右滑動 / 點擊 ⭐**：將單字加入「加星號」收藏，並切換至下一張。
    *   **向左滑動 / 點擊 ➡️**：直接切換至下一張單字卡（一般跳過）。
    *   **鍵盤快捷鍵**：支援 `Space` (播放發音)、`←` (下一張)、`→` (加星號下一張)、`Esc` (退出卡片模式)。
*   🔊 **雙口音自動播放**：每張單字卡切換時，自動依序播放 **美式英語 (US) 🇺🇸 → 英式英語 (GB) 🇬🇧** 發音，間隔 0.6 秒。
*   ⭐ **收藏功能**：一鍵將難記的單字加入收藏，並可一併在「加星號的單字」分頁進行集中複習與卡片演練。
*   📱 **PWA 支援**：支援手機「加入主畫面」安裝，安裝後即使在**無網路（離線）狀態**下也能正常開啟使用。

## 📱 手機安裝說明 (PWA)
在手機與電腦連線至相同網域或直接存取 GitHub Pages 網址時：
1.  **iOS (Safari)**: 點擊瀏覽器下方的「分享」按鈕 📤，選擇 **「加入主畫面」**。
2.  **Android (Chrome)**: 點擊右上角選單 ⋮，選擇 **「安裝應用程式」** 或 **「新增至主畫面」**。

## 🛠️ 開發與本地執行
本專案為純前端應用，使用 Vanilla HTML/CSS/JS 撰寫。

### 本地伺服器啟動
PWA Service Worker 需要在安全通訊協定 (HTTPS) 或本地 `localhost` 下運作。請使用靜態網頁伺服器開啟：
```bash
# 使用 npx 啟動靜態伺服器 (預設使用 port 8080)
npx serve -l 8080
```
瀏覽器打開 `http://localhost:8080` 即可運作。
